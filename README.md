# Miru Extension

Official extension repository for [Animiru (Widevine Edition)](https://github.com/kartik-commits/Animiru-fork).

---

## How to Add to Animiru

1. Open **Animiru**.
2. Navigate to **More → Settings → Browse → Extension Repositories**.
3. Tap **Add repository**.
4. Paste the following URL:

```text
https://raw.githubusercontent.com/kartik-commits/miru-extension/main/index.min.json
```

5. Go to **Browse → Extensions** to install and manage your extensions.
